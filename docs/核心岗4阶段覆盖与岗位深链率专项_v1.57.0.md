# 核心岗4阶段覆盖与岗位深链率专项（v1.57.0）

更新时间：2026-02-19（UTC）
适用范围：下一批次专项（8个优先行业）

## 1. 专项目标
- 目标1：提高核心岗“笔试+面试”四阶段覆盖（提前批/主批/补录/实习转正）。
- 目标2：提高岗位画像证据深链率（岗位详情页/公告详情页，不可仅首页）。
- 专项口径：先核心岗后全岗位，先官方深链后平台样本，平台受限必须留待补槽位。

## 2. 专项范围（行业ID）
- `IND_INTERNET_AI`
- `IND_FIN_BANK`
- `IND_ENERGY_UTILITIES`
- `IND_PUBLIC_INSTITUTION`
- `IND_FIN_SECURITIES_FUND`
- `IND_NEW_ENERGY`
- `IND_TELECOM_OPERATOR`
- `IND_AUTO_INTELLIGENT_DRIVING`

## 3. 执行顺序
1. 核心岗4阶段：逐岗位补齐缺失阶段题（笔试与面试分别计算，不可互相替代）。
2. 岗位深链：逐岗位替换证据为详情深链（优先企业校招岗位页，再用官方公告页）。
3. 平台样本：补城市/薪资/轮次/高频追问；样本不足时写入`pending`槽位而非伪造。

## 4. 平台受限时的待补槽位（必须保留）
- 必填字段：
  - 岗位名称
  - 岗位详情深链URL

  - 批次/轮次
  - 发布时间
  - 样本量
  - 截图路径
  - 来源类型
  - 备注

  - `pending_deep_link_backfill`
  - `pending_platform_verification`
- 必填说明：
  - 需要什么信息（缺失字段）
  - 该如何搜索（步骤）
  - 从哪里搜索（平台入口+检索词）
  - 计划回填时间与责任人

## 5. 检索路径与方法
- BOSS直聘（网页优先）：
  - 入口：<https://www.zhipin.com/web/geek/job?query=校招>
  - 检索式：`应届生 + 行业关键词 + 岗位关键词`
- 小红书（网页受限时用App）：
  - 入口：<https://www.xiaohongshu.com/search_result/?keyword=校招>
  - 检索式：`行业关键词 + 校招 + offer + 面经 + 薪资`
- 官方优先（主证据）：
  - 教育部：<https://www.moe.gov.cn/>
  - 人社部：<https://www.mohrss.gov.cn/>
  - NCSS：<https://www.ncss.cn/>
  - 企业校招岗位详情页（腾讯/阿里/字节/运营商/银行/能源集团等）

## 6. 可用信息源分层
- L1（主结论必须依赖）：
  - 政策与招录：教育部、人社部、NCSS、国家公务员局、人事考试网、行业主管部门
  - 企业岗位：企业校招岗位详情页/公告详情页
- L2（交叉验证）：
  - BOSS、智联、前程无忧、猎聘及研究院
  - 地方统计与行业公开数据
- L3（扩题主力，结论降权）：
  - 牛客、论坛面经、小红书
  - 必须标注“回忆题/非官方原卷”、帖子ID、时间戳、截图路径
