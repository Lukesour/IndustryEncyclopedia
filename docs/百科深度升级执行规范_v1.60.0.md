# 百科深度升级执行规范（v1.60.0）

更新时间：2026-02-19

## 1. 目标

让用户不跳转外站，仅依靠百科完成：

1. 行业认知
2. 岗位选择
3. 投递规划
4. 笔面试训练
5. 复盘与转岗决策

## 2. 岗位扩容规则

- 不统一岗位数量，按行业复杂度分层扩容。
- 高复杂行业（互联网AI/半导体/智驾/新能源/生物医药）：优先扩技术分支岗位。
- 中复杂行业（金融、咨询、物流、制造、跨境）：优先扩业务流程分支岗位。
- 公共体系行业（公务员/事业单位/央国企）：优先扩“地区/条线/层级”场景岗位。

## 3. 题库扩容规则

- 阶段覆盖必须包含：提前批、主批、补录、实习转正。
- 题库不再只满足最低门槛，采用“可实战”分层：
  - 核心岗位：14-20（笔）/14-20（面）
  - 主流岗位：10-14（笔）/10-14（面）
  - 长尾岗位：8-10（笔）/8-10（面）
- 所有新增题目必须绑定岗位ID与阶段字段，禁止无角色归属的泛题堆积。

## 4. 岗位画像字段（必须）

- 岗位职责边界
- 核心KPI
- 典型项目
- 常见失败案例
- 关键扣分点
- 90天准备计划
- 转岗路径
- 证据链与来源字段

## 5. 平台受限处理（BOSS/小红书）

- 允许留空，不允许伪造。
- 必须保留：缺失原因、检索方式、检索时间、预计回填时间。
- 必填留空位字段：
  - 岗位名称
  - 城市
  - 公司层级
  - 批次/轮次
  - 薪资区间P25/P50/P75
  - 发布时间
  - 来源链接或帖子ID
  - 样本量
  - 截图路径与截图时间

## 6. 信息源分层

- L1（强结论）：政策、监管、企业官方招聘页。
- L2（交叉验证）：BOSS、智联、51job、猎聘与研究报告。
- L3（扩题补充）：牛客、小红书面经（必须标注回忆样本）。

## 7. 发布前检查清单

1. 行业岗位数是否达到本轮目标。
2. 每岗位笔面试题量是否达到分层目标。
3. 4阶段是否覆盖。
4. 岗位画像字段是否完整。
5. 是否存在平台受限未标注的伪造字段。
6. 来源是否满足 L1/L2/L3 使用边界。
