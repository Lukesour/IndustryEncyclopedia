# 平台样本补录指引（v1.42.1）

更新时间：2026-02-18
适用范围：行业百科23个行业词条的`自定义扩展`与`薪酬快照_按城市_按公司层级_按岗位`

## 1. 可达性现状（联网核验）
- BOSS直聘首页：`https://www.zhipin.com`（HTTP 200）
- BOSS职位搜索页：`https://www.zhipin.com/web/geek/job?query=校招`（HTTP 200）
- 智联职位搜索页：`https://sou.zhaopin.com/?jl=530&kw=校招`（HTTP 200）
- 猎聘职位搜索页：`https://www.liepin.com/zhaopin/?key=校招`（HTTP 200）
- 前程无忧入口：`https://we.51job.com/`（HTTP 200）
- 小红书网页搜索：`https://www.xiaohongshu.com/search_result/?keyword=校招`（HTTP 404，存在风控/登录态限制）

说明：小红书建议改为App端人工检索+截图补录；BOSS可优先使用网页搜索页。

## 2. 运营必须补录字段
每条样本至少补齐以下字段：
- 岗位名称
- 城市
- 公司层级（t1_head / t2_strong / t3_regional / public_sector）
- 薪资区间（至少可换算到年化P25/P50/P75）
- 发布时间（YYYY-MM-DD）
- 来源链接（岗位URL或帖子链接）
- 样本量口径（同类岗位聚合条数）
- 证据截图路径（建议存储到内部盘）

## 3. 检索步骤
### 3.1 BOSS直聘（优先）
1. 打开`https://www.zhipin.com/web/geek/job?query=<关键词>`。
2. 选择筛选：`应届生/校招`、目标城市、目标岗位。
3. 对同类岗位抽样>=20条，记录薪资区间并统一口径。
4. 填入行业词条对应字段并附岗位链接。

### 3.2 小红书（补充）
1. 在App内搜索`<行业关键词> 校招 offer 薪资 面经`。
2. 优先采集近90天帖子，记录城市、岗位、薪资、批次（提前批/秋招/春招）。
3. 仅作为L2补充证据，必须标注“回忆样本”。
4. 对无法公开直链的内容，保存截图并补帖子ID。

## 5. 质检规则
- 同一岗位同一城市去重（公司+岗位名+发布时间）。
- 每行业至少覆盖6城、6岗、2种公司层级。
- 小红书样本必须降权标记，不得单独作为A档结论依据。
- 出现“无发布时间/无城市/无薪资区间”的样本一律不入库。
