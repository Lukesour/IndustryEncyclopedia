# 信息源分级与抓取规范（v1.34.0）

更新时间：2026-02-23

## 1. 证据分级

- L1（主证据）：部委/监管/企业官方招聘页与岗位详情页
- L2（交叉验证）：BOSS、智联、51job、猎聘、地方统计公开数据
- L3（训练补充）：牛客、小红书、论坛面经（必须标注回忆样本）

## 2. 使用规则

- 趋势、薪酬、政策结论必须 `L1+L2` 双证据。
- L3 仅用于扩题、追问链和失分点，不单独支撑强结论。
- 题库条目必须保留：年份、轮次、样本量、来源链接。

## 3. 平台受限与留空

当 BOSS/小红书无法稳定获取时：

1. 保留留空字段，不得伪造。
2. 记录失败原因（404/风控/登录限制）。
3. 记录检索入口和查询词。
4. 记录检索时间与预计回填时间。

## 4. 推荐检索词

- BOSS：`应届生 + 行业 + 岗位 + 城市`
- 小红书：`行业 + 岗位 + 面经/校招/offer`
- 牛客：`岗位 + 笔试/面试 + 年份 + 公司`

## 5. 必填元字段

每条证据至少包含：

- `source_id`
- `source_url`
- `source_name`
- `source_type`
- `publish_date`
- `accessed_at`
- `captured_at`
- `data_period`
- `sample_size`
- `confidence`
