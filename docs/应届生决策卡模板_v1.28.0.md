# 应届生决策卡统一模板（v1.28.0）

## 使用目标
- 把行业信息从“可读”升级为“可比较、可投递、可执行”。
- 每个行业固定输出三张卡：`去哪投`、`何时投`、`值不值投`。

## 卡片1：去哪投
- 主投岗位：`岗位名称 + 典型公司层级 + 典型城市`
- 备投岗位：`岗位名称 + 转换门槛`
- 投递建议：`A/B/C池`（A核心冲刺，B稳妥匹配，C保底）
- 证据字段：`primary_source_id` + `secondary_source_ids`

## 卡片2：何时投
- 年度窗口：`秋招提前批 / 秋招主批 / 春招补录 / 社招转校招`
- 月度节点：`网申开始-笔试-面试-offer`四段关键日期
- 节奏策略：`首轮投递日期`、`补投触发条件`、`止损节点`
- 证据字段：`timeline_source_id` + `policy_source_id`

## 卡片3：值不值投
- 收益侧：`薪资潜力`、`成长性`、`可迁移能力`
- 成本侧：`上岸难度`、`工作强度`、`城市生活成本压力`
- 结论：`推荐/谨慎/不推荐`（需给出一句“为什么”）
- 可靠度标签：`A/B/C`（按样本量、来源层级、时效计算）

## 可靠度标签规则（建议）
- `A`：至少2个一级来源 + 1个二级来源，且核心证据在180天内。
- `B`：至少1个一级来源 + 1个二级来源，部分证据超过180天。
- `C`：仅单一来源或回忆样本为主，结论需标注“待你补充”。

## 字段建议（写入JSON时）
- `decision_cards.where_to_apply`
- `decision_cards.when_to_apply`
- `decision_cards.worth_it_or_not`
- `decision_cards.reliability_tier`
- `decision_cards.evidence_chain`

## 证据源优先级
- 一级：教育部、人社部、国家统计局、国务院/中国政府网、NCSS、国家公务员局、部委与监管机构、企业校招官网公告页。
- 二级：智联/BOSS/猎聘/前程无忧官方报告页、行业协会公开报告、上市公司年报人力章节。
- 回忆样本：牛客/校招社区（仅做补充，须降权并标注非官方原卷）。
