## 2. 平台受限时必须补的字段
- 岗位名称
- 城市
- 公司层级
- 批次/轮次
- 薪资区间（建议P25/P50/P75）
- 发布时间
- 来源链接或帖子ID
- 样本量
- 截图路径与截图时间

## 3. 如何搜索（统一规则）
- 先官方后平台：先企业官网岗位详情页/公告页，再补平台样本。
- BOSS检索：`应届生 + 行业 + 岗位`
- 小红书检索：`行业 + 岗位 + 校招/面经/offer`
- 留证规则：
  - 必须保留发布时间与截图时间戳。
  - 缺少城市/薪资/发布时间的样本，仅可标注为低置信补充，不进入强结论。
