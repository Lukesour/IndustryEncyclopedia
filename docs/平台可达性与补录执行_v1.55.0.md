## 2. 补录最低字段（不可缺）
- 岗位名称
- 城市
- 公司层级（`t1_head` / `t2_strong` / `t3_regional` / `public_sector`）
- 批次/轮次（提前批/主批/补录/实习转正）
- 题目或岗位链接
- 发布时间（YYYY-MM-DD）
- 样本量
- 证据截图路径
- 来源类型
- 备注（是否回忆题、是否官方原卷、样本限制）

## 3. 搜索顺序（必须执行）
1. 先查L1官方与企业校招岗位详情页，确定岗位定义和批次口径。
2. 再查BOSS补齐城市/薪资/公司层级分布样本。
3. 最后用小红书补“回忆题/面经”样本，必须降权标注并留截图。

## 4. 平台受限时的缺口位处理
- 必留缺口状态：`pending_platform_verification`
- 必填缺口说明：缺哪类字段、去哪里补、用什么检索词、谁负责补、最晚补录日期
- 禁止行为：
  - 用历史样本伪造最新日期
  - 用首页链接替代岗位详情链接
  - 样本量不足仍输出A档结论

## 5. 建议检索模板
- BOSS：`应届生 <行业关键词> <岗位关键词>`
- 小红书：`<行业关键词> 校招 offer 薪资 面经`
- 官方：`<企业名> 校园招聘 岗位详情`
