# 信息源分级与抓取规范（v1.32.0）

## 1. 证据分级
- 一级证据（优先）：部委/主管机关/企业官方招聘与公告页面
- 二级证据（补充）：招聘平台研究报告、行业研究机构季报
- 三级证据（降权）：面经社区、回忆题、论坛帖

## 2. 一级来源（按模块）

### 2.1 就业与招录政策
- 教育部：[https://www.moe.gov.cn/](https://www.moe.gov.cn/)
- 人社部：[https://www.mohrss.gov.cn/](https://www.mohrss.gov.cn/)
- 国家大学生就业服务平台（NCSS）：[https://www.ncss.cn/](https://www.ncss.cn/)
- 中国公共招聘网：[https://chinajob.mohrss.gov.cn/](https://chinajob.mohrss.gov.cn/)
- 国家公务员局：[http://www.scs.gov.cn/](http://www.scs.gov.cn/)
- 中国人事考试网：[http://www.cpta.com.cn/](http://www.cpta.com.cn/)

### 2.2 行业监管与景气（示例）
- 工信部：[https://www.miit.gov.cn/](https://www.miit.gov.cn/)
- 商务部：[https://www.mofcom.gov.cn/](https://www.mofcom.gov.cn/)
- 国家能源局：[https://www.nea.gov.cn/](https://www.nea.gov.cn/)
- 证监会：[https://www.csrc.gov.cn/](https://www.csrc.gov.cn/)
- 国资委：[http://www.sasac.gov.cn/](http://www.sasac.gov.cn/)
- 交通运输部（邮政运行）：[https://www.mot.gov.cn/](https://www.mot.gov.cn/)
- 国家新闻出版署（游戏版号）：[https://www.nppa.gov.cn/](https://www.nppa.gov.cn/)
- 国家广播电视总局：[https://www.nrta.gov.cn/](https://www.nrta.gov.cn/)

### 2.3 典型企业端（校招节奏与岗位结构）
- 企业官网招聘页/校园招聘页（应优先落到岗位页或公告页，不只首页）
- 国央企招聘子站/子公司招聘页

## 3. 二级来源（交叉验证）
- 智联研究院、BOSS直聘研究院、前程无忧、猎聘
- 地方统计局、地方发改/工信/商务公开数据

## 4. 三级来源（需降权）
- 牛客、校招社区、论坛面经
- 必须标注：`回忆样本/非官方原卷/仅供训练参考`

## 5. 抓取字段（强制）
每条事实至少记录：
- `source_id`
- `source_url`
- `source_name`
- `source_type`
- `publish_date`（优先）
- `accessed_at`
- `captured_at`
- `data_period`（如果是统计数据）
- `sample_size`
- `confidence`

## 6. 双证据链要求
- 普通事实：至少1个一级来源
- 关键结论（薪酬、趋势、招录窗口）：1个一级 + 1个二级交叉

## 7. 登录与 Cookie 规则
优先使用无需登录的官方来源。以下站点常见登录限制（仅在确有必要时提交 Cookie）：
- BOSS直聘（详情岗位与部分数据页）
- 智联招聘（部分研究页或岗位详情）
- 猎聘（部分薪酬与人才洞察页）
- 牛客（部分题库与讨论串）

提交建议：仅上传目标域名的最小必要 Cookie，不要上传全浏览器 Cookie。
