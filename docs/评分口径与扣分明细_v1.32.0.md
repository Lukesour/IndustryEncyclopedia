# 评分口径与扣分明细（v1.32.0）

## 1. 目标
将“质量分”拆解为可解释因子，回答用户最关心的问题：
- 为什么这个行业比另一个行业更值得投？
- 分数低是因为数据旧、样本少，还是来源不可靠？

## 2. 总分结构（建议展示给用户）
- 数据完整度（coverage）
- 证据完整度（evidence）
- 真实性（real_data_ratio）
- 时效性（freshness）
- 来源独立性（source concentration penalty）
- 决策可用性（question depth + role coverage）

建议前端展示：`总分 + 扣分明细`，而非只显示单一分值。

## 3. 扣分明细字段（建议）
每个行业输出以下字段：
- `penalty_source_concentration`: 来源集中度惩罚（top1/top5超阈值时触发）
- `penalty_freshness`: 超过180天证据占比过高时触发
- `penalty_evidence_lowsample`: verified记录样本量低于门槛时触发
- `penalty_role_coverage`: 笔试/面试岗位覆盖不足时触发
- `penalty_event_density`: 事件日志密度不足或近180天事件不足时触发

## 4. 给应届生的解释模板
- 去哪投：看`岗位密度 + 事件动量 + 来源可信度`
- 何时投：看`月度时间线 + 最近90天事件`
- 值不值投：看`薪酬观察层 + 城市成本 + 转化率`

## 5. 本版本执行约束
- 事件与政策结论优先使用一级来源。
- 关键结论必须有双证据链（主证据+交叉证据）。
- 回忆题/社区信息只作为补充证据，必须降权标注。

## 6. v1.43.0新增门禁（发布阻断）
- `policy_title_source_mismatch_hits`: 政策标题与证据来源语义不一致（如“国家统计局”标题却指向行业部委源）。
- `policy_date_source_mismatch_hits`: 政策条目日期与证据`source_date`不一致。
- `stats_data_period_missing_hits`: 统计类证据缺少`data_period`。
- `decision_salary_source_invalid_hits`: 决策卡`salary_source_id`不是薪酬统计源（禁止公司官网充当薪酬源）。
- `decision_evidence_non200_hits`: 决策链三源（timeline/policy/salary）存在非200来源。

## 7. v1.53.0新增深度硬门禁（发布阻断）
- `role_count_coverage_hits`: 行业岗位数未达到目标（默认每行业24岗）。
- `written_per_role_hits` / `interview_per_role_hits`: 单岗位题量未达标（默认每岗12笔/12面）。
- `stage_coverage_per_role_hits`: 岗位在笔试/面试任一集合未覆盖4阶段。
- `job_detail_url_depth_hits`: 岗位证据链接深度不足（岗位详情页占比未达门槛）。
- `template_reuse_hits`: 题库/岗位卡模板复用超阈值（框架Top1/Top3、追问Top3、淘汰点Top1）。

说明：
- v1.53.0起，上述深度项不再只是看板指标，而是与旧门禁同级的阻断条件。
- 目标值读取`治理配置.发布硬门槛`，可按版本迭代调整。
