# 评分口径与扣分明细（v1.32.0）

## 1. 目标
将“质量分”拆解为可解释因子，回答用户最关心的问题：
- 为什么这个行业比另一个行业更值得投？
- 分数低是因为数据旧、样本少，还是来源不可靠？

## 2. 总分结构（建议展示给用户）
- 数据完整度（coverage）
- 证据完整度（evidence）
- 真实性（real_data_ratio）
- 时效性（freshness）
- 来源独立性（source concentration penalty）
- 决策可用性（question depth + role coverage）

建议前端展示：`总分 + 扣分明细`，而非只显示单一分值。

## 3. 扣分明细字段（建议）
每个行业输出以下字段：
- `penalty_source_concentration`: 来源集中度惩罚（top1/top5超阈值时触发）
- `penalty_freshness`: 超过180天证据占比过高时触发
- `penalty_evidence_lowsample`: verified记录样本量低于门槛时触发
- `penalty_role_coverage`: 笔试/面试岗位覆盖不足时触发
- `penalty_event_density`: 事件日志密度不足或近180天事件不足时触发

## 4. 给应届生的解释模板
- 去哪投：看`岗位密度 + 事件动量 + 来源可信度`
- 何时投：看`月度时间线 + 最近90天事件`
- 值不值投：看`薪酬观察层 + 城市成本 + 转化率`

## 5. 本版本执行约束
- 事件与政策结论优先使用一级来源。
- 关键结论必须有双证据链（主证据+交叉证据）。
- 回忆题/社区信息只作为补充证据，必须降权标注。
