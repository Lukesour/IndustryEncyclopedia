## 2. 模块映射

- 政策变化日志：至少 1 条一级来源；关键结论再加 1 条二级来源。
- 年度校招时间线：优先“官方公告页 + NCSS/公共招聘网活动页”。
- 从业者访谈/案例复盘：优先政府或企业官方页；回忆样本仅作补充并标记真实性等级。
- 行业事件日志：统一 `fact + impact + industry_indicator + evidence_chain`。
- 薪酬模块：
  - 观察层：`gov_stat_anchor` / `jd_posted_range` / `offer_recall` / `commercial_report`
  - 估算层：仅缺口补位，必须与观察层分开展示。
- 题库模块：官方样题 > 官方说明 > 回忆题；回忆题必须标注“非官方原卷”。

## 3. 日期与可追溯字段（强制）

每条事实固定记录：
- `publish_date`（新鲜度主口径）
- `source_date`（兼容日期，与 publish_date 对齐）
- `accessed_at`
- `captured_at`
- `data_period`（如 `2025Q4`）

## 4. 质量门槛（v1.29）

- 来源集中度：`top1 <= 7.5%`、`top5 <= 26%`。
- 事件日志：每行业 `>=8` 条，且近180天 `>=6` 条。
- 题库深度：重点行业至少 `8条笔试 + 8条面试`。
- 访谈/案例：公共部门行业目标 `>=5`。
- 发布门禁：`has_blockers=false`（含 source_id-host 一致性检查）。

## 5. 登录与 Cookie 说明

- 当前一级官方来源（教育部、人社部、政府网、统计局、部委公告）无需登录即可抓取。
- 若后续要采集“需要登录的招聘平台详情页/历史帖”，再按具体网站补充 Cookie。
- 建议只上传最小必要 Cookie：`session`、`csrf/token`，避免上传完整浏览器 Cookie 包。
