# 题库同权与扩容规则（v1.45.0）

更新时间：2026-02-19
适用范围：`行业百科.json` 全量 23 行业词条

## 1. 核心目标
- 用户不跳外站，仅依靠百科即可完成行业理解、岗位选择、准备路径设计。
- 题库扩容优先级高于形式完整度：先把岗位与题量做厚，再做精细打磨。

## 2. 题库同权规则（新增）
- 作用范围：`笔试真题库`、`面试真题库`
- 同权标签：
  - `official_original`
  - `real_recall`
  - `jd_mapping`
- 训练权重：三类题目同权（1.0 / 1.0 / 1.0）
- 强制透明字段：来源类型、年份、批次、轮次、样本量、来源链接

说明：
- 在题库训练模块中，回忆题与官方题同权使用。
- 在行业趋势/薪酬结论模块，仍需遵循 L1+L2 交叉证据规则。

## 3. 扩容目标（v1.45）
- 每行业岗位目标：24
- 每岗位笔试题目标：12
- 每岗位面试题目标：12
- 阶段覆盖目标：提前批 / 主批 / 补录 / 实习转正

## 4. 去模板化目标
- `follow_up_questions` Top3 复用率：< 35%
- `answer_framework` Top1 占比：< 40%
- 优先增加岗位特异化追问链和扣分点。

## 5. 来源颗粒度目标
- 优先岗位详情页/公告页/流程页，不使用站点首页替代岗位证据。
- 题库条目需绑定可追溯 URL 与时间信息。

## 6. 平台缺口补录（BOSS/小红书）
- BOSS：优先网页检索，按“应届生/校招 + 城市 + 岗位”采样。
- 小红书：网页端常见 404/风控，改 App 端检索并截图留证。
- 缺口样本必填：岗位名称、城市、公司层级、批次/轮次、来源链接(或帖子ID)、发布时间、样本量、截图路径。

## 7. 执行清单文件
- 结构化清单：`reports/全量扩容执行清单_v1.45.0.json`
- 可读清单：`reports/全量扩容执行清单_v1.45.0.md`
