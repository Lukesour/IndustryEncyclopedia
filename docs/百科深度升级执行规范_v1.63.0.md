# 百科深度升级执行规范（v1.63.0）

更新时间：2026-02-23

## 1. 本版目标

在不牺牲真实性的前提下，继续推进“用户不跳外站即可完成选岗与准备”：

1. 扩充细分岗位树
2. 补齐岗位决策深度字段
3. 强化题库训练系统化
4. 平台受限字段留空并可回填

## 2. 本版已执行动作

- 对8个低配行业核心岗位执行逐岗补深：
  - 新增/补齐 `career_outlook_3to5_year`
  - 新增/补齐 `typical_work_week`
  - 新增/补齐 `switch_directions`
  - 新增/补齐 `prepare_180d_plan`
  - 每岗新增笔试2题、面试2题
- 对5个低扩容落地行业新增细分岗位（ROLE_022）：
  - 每岗补齐职业决策六件套
  - 每岗新增笔试8题、面试8题
  - 写入平台受限留空检索卡
- 对全库题目补齐 `scenario_bucket` 并逐岗补到5类场景桶：
  - `business_scenario`
  - `system_process`
  - `failure_review`
  - `cross_team_collaboration`
  - `metric_tradeoff`

## 3. 平台受限处理（本版强制）

当 BOSS/小红书不可稳定抓取时：

1. 保留字段留空，不得伪造
2. 记录 HTTP 状态、检查日期
3. 给出搜索入口与查询词
4. 给出下一次回填动作

必填可留空字段：

- 城市分布
- 薪资区间 P25/P50/P75
- 发布时间
- 批次/轮次
- 帖子ID/链接
- 样本量
- 截图时间

## 4. 证据分层（延续）

- L1：政策/监管/企业官方岗位页
- L2：BOSS/智联/51job/猎聘/地方统计
- L3：牛客/小红书（回忆样本，需标注）

强结论（趋势/薪酬/政策）必须 `L1+L2`。

## 5. 发布前检查

1. 新增岗位是否同步题库覆盖（>=8/8）
2. 岗位六件套是否完整
3. 场景桶是否达到5类
4. 平台缺失字段是否保留留空并可回填
5. 证据来源是否满足L1/L2/L3边界
