# 23行业分行业扩容执行清单（v1.60.0）

更新时间：2026-02-19

目标：让用户只依靠百科完成“选行业-选岗位-定投递节奏-做笔面训练-执行复盘”。

## 一、执行原则（本版已落地）

1. 题库从“门槛可用”升级为“实战可练”：本版执行目标为每岗10笔+10面，继续覆盖提前批/主批/补录/实习转正四阶段。
2. 按行业复杂度差异化扩容岗位：不统一岗位数量，高复杂行业优先扩技术分支，公共体系优先扩岗位场景分支。
3. 先补“角色专属题深度”再补泛题：每新增岗位必须带角色专属笔面题，避免仅堆通用题。
4. 平台受限不伪造：BOSS/小红书遇到风控或登录限制时，保留留空位并写清检索方式与缺失原因。
5. 证据分层：L1（官方/企业）用于强结论，L2用于交叉验证，L3仅用于题库扩题与面经补充。
