## 2. 平台受限时必须留空的字段

- 城市分布
- 薪资区间P25/P50/P75
- 发布时间
- 批次/轮次
- 帖子ID/链接
- 样本量
- 截图时间

## 3. 回填检索方法（统一模板）

- BOSS：`应届生 + 行业 + 岗位 + 城市`，筛选“近30天/本科及以上/校招”。
- 小红书：`行业 + 岗位 + 面经/校招/offer`，优先近一年帖子并记录帖子ID。
- 牛客：`岗位 + 笔试/面试 + 年份 + 公司`，用于追问链与评分点补强。

## 4. 不可抓取处理规则

1. 不可用估算值覆盖缺失字段。
2. 保留缺失原因与检索时间（绝对日期）。
3. 记录下一次回填时间（默认两周内）。
