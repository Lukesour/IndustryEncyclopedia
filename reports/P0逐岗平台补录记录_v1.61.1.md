# P0逐岗平台补录记录（v1.61.1）

更新时间：2026-02-20

目标：针对已补深的16个P0岗位，补录平台样本字段；若BOSS/小红书无法稳定获取，保留留空位并记录检索路径。

## 必补字段

- 岗位名称
- 城市
- 公司层级
- 批次/轮次
- 薪资P25/P50/P75
- 发布时间
- 来源链接或帖子ID
- 样本量
- 截图路径与截图时间
- 缺失原因
- 预计回填时间

## 检索方法

1. BOSS直聘网页端：`应届生 + 行业 + 岗位 + 城市`
2. 小红书：`行业 + 岗位 + 校招/面经/offer + 年份`
3. 牛客：`岗位关键词 + 笔试/面试 + 年份`
4. 先核对企业官方岗位页，再回填平台样本，避免岗位口径漂移。
