# 23行业逐个填写任务板（v1.53.0）

更新时间：2026-02-19（v1.53深度硬门禁口径）
目标：让用户不跳出百科即可完成“选行业-选岗位-定准备路径-执行备考-复盘止损”。

统一回填规则（所有行业）
1. 岗位目标：每行业24岗（现14岗，新增10岗；其余2岗作为备选）。
2. 题库目标：每岗位12笔试+12面试（四阶段覆盖：提前批/主批/补录/实习转正）。
3. 题库同权：official_original、real_recall、jd_mapping同权训练。
4. 字段强制：题目必须含来源类型、年份、批次、轮次、样本量、链接。
5. 平台受限：BOSS优先网页；小红书若网页受限，改App+截图补录。
6. 必填缺口字段：岗位名称、城市、公司层级、批次/轮次、题目或岗位链接、发布时间、样本量、截图路径、来源类型、备注。
7. 平台不可达留空规则：若无法稳定获取，必须保留“待补槽位”并写明 `缺失字段`、`检索词`、`检索入口URL`、`最后尝试时间`、`截图路径`、`下一次回填时间`。
8. Boss检索入口：`https://www.zhipin.com/web/geek/job?query=校招`，建议筛选“应届生/校招 + 城市 + 岗位”。
9. 小红书检索入口：App端搜索“行业关键词 + 校招 + 面经 + offer”，网页受限时记录帖子ID与截图时间戳。

统一岗位卡模板（逐个岗位填写）
- 岗位名称
- 岗位族（技术/产品/运营/职能/销售/研究等）
- 典型职责（3-5条）
- 核心产出物（2-3项，可量化）
- 典型项目（1-2个，可写到简历）
- 常见淘汰点（2-4条）
- 入门门槛（学历/技能/实习）
- 90天准备动作（按周）
- 转岗桥梁（可迁移到哪些岗位）
- 证据来源URL（至少2条）

统一题目卡模板（逐题填写）
- 题目ID
- 题目类型（official_original/real_recall/jd_mapping）
- 岗位
- 阶段（提前批/主批/补录/实习转正）
- 轮次（笔试1轮/笔试2轮/一面/二面/HR面）
- 题干
- 评分维度
- 高分信号
- 常见扣分点
- 参考解法框架
- 追问链（至少3问）
- 来源字段（source_id/source_url/source_date/sample_size/confidence）
